# ⏰ 시간 탐험대 (Time Adventure)

초등학교 저학년 어린이가 **시간과 분의 관계를 직접 조작하며 익히는 웹 학습 게임**입니다.

- 60분 = 1시간
- 90분 = 1시간 30분
- 1시간 반 = 90분
- 200분 = 3시간 20분

단순히 정답을 외우거나 계산식을 보여주는 대신, **60분을 묶고 1시간을 풀어보는 과정**을 통해 시간 단위 변환을 이해하도록 설계했습니다.

## 🌐 바로 사용하기

https://doworld-dev.github.io/time-adventure/

별도의 설치나 로그인 없이 브라우저에서 바로 사용할 수 있습니다. 모바일과 태블릿에서 손가락으로 사용하는 환경을 우선 고려합니다.

## 🎯 학습 목표

> **60분을 묶으면 1시간, 1시간을 풀면 60분**

### 분 → 시간

`200분 → 60분씩 묶기 → 묶음과 남은 분 관찰 → 시간/분 선택 → 정답 확인`

### 시간 → 분

`2시간 30분 → 1시간씩 풀기 → 60 + 60 + 30 관찰 → 답 선택 → 정답 확인`

전체 UX는 **조작 → 관찰 → 답하기 → 피드백** 순서를 따릅니다.

## 🎚 난이도

| 난이도 | 분 → 시간 | 시간 → 분 |
| --- | --- | --- |
| 🌱 쉬움 | 60, 90, 120, 150, 180, 200분 | 1~3시간 + 0/30분 |
| 🌿 보통 | 70~240분, 10분 단위 | 1~3시간 + 0/10/20/30/40/50분 |
| 🌳 도전 | 70~360분, 10분 단위 | 1~5시간 + 0/10/20/30/40/50분 |

현재 난이도는 주로 문제 숫자의 범위와 복잡도에 차이가 있습니다.

## ✨ 현재 기능

- 무한 랜덤 문제 생성
- `분 → 시간`, `시간 → 분` 랜덤 출제
- 최근 문제 반복 최소화
- 60분 묶기 / 1시간 풀기
- 시간/분 답 선택 및 객관식 계산
- 쉬움 / 보통 / 도전 난이도
- 점수 및 연속 정답
- 모바일/태블릿 대응
- GitHub Pages 정적 배포
- Google Analytics 4 페이지뷰 및 학습 행동 이벤트 추적

## 📊 Analytics

Google Analytics 4를 사용합니다.

- Measurement ID: `G-PZBDJ1CESH`
- 방식: `gtag.js`
- `quiz-proverb` 프로젝트와 같은 GA4 측정 ID 사용

### Custom events

- `problem_start` — 새 문제 출제
- `difficulty_change` — 난이도 변경
- `bundle_60` / `bundle_undo` — 60분 묶기/되돌리기
- `unpack_hour` / `unpack_undo` — 1시간 풀기/되돌리기
- `answer_option_select` — 답 선택
- `answer_check` — 정답 확인
- `answer_correct` / `answer_wrong` — 정답/오답
- `problem_reset` — 문제 초기화
- `next_problem` — 다음 문제 이동

이벤트에는 난이도, 문제 유형, 문제 값, 선택값, 점수, 연속 정답 등의 분석용 파라미터를 함께 전송합니다.

## 🗂 프로젝트 구조

```text
time-adventure/
├── index.html   # 화면 구조 + GA4 초기화
├── style.css    # UI 및 반응형 스타일
├── app.js       # 문제 생성, 상태, 정답 판정, GA4 이벤트
├── .nojekyll    # GitHub Pages 정적 파일 처리
└── README.md
```

순수 HTML/CSS/JavaScript 프로젝트이며 별도의 빌드 과정이나 외부 UI 라이브러리가 없습니다.

## 🚀 로컬 실행

```bash
git clone https://github.com/doworld-dev/time-adventure.git
cd time-adventure
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 📦 배포

GitHub Pages에서 `main` 브랜치의 `/ (root)`를 배포합니다. `main` 변경사항이 동일한 Pages 주소에 반영됩니다.
