# ⏰ 시간 탐험대 (Time Adventure)

초등학교 저학년 어린이가 **시간과 분의 관계를 직접 조작하며 익히는 웹 학습 게임**입니다.

- 60분 = 1시간
- 90분 = 1시간 30분
- 1시간 반 = 90분
- 200분 = 3시간 20분

단순히 정답을 외우거나 계산식을 보여주는 대신, **60분을 묶고 1시간을 풀어보는 과정**을 통해 시간 단위 변환을 이해하도록 설계했습니다.

## 🌐 바로 사용하기

https://doworld-dev.github.io/time-adventure/

별도의 설치나 로그인 없이 브라우저에서 바로 사용할 수 있습니다. 모바일과 태블릿에서 손가락으로 사용하는 환경을 우선 고려합니다.

## 🎯 학습 목표

핵심 개념은 하나입니다.

> **60분을 묶으면 1시간, 1시간을 풀면 60분**

두 방향의 문제를 같은 원리로 학습합니다.

### 분 → 시간

예: `200분 → ?`

1. 200분에서 60분씩 묶습니다.
2. 더 이상 60분을 만들 수 없을 때까지 반복합니다.
3. 만들어진 60분 묶음과 남은 분을 관찰합니다.
4. 몇 시간 몇 분인지 직접 선택합니다.
5. 정답을 확인합니다.

### 시간 → 분

예: `2시간 30분 → ?`

1. 1시간을 하나씩 60분으로 풉니다.
2. 모든 시간을 풀어냅니다.
3. `60 + 60 + 30`처럼 변환된 값을 관찰합니다.
4. 모두 몇 분인지 직접 선택합니다.
5. 정답을 확인합니다.

즉 전체 UX는 **조작 → 관찰 → 답하기 → 피드백** 순서를 따릅니다.

## 🎚 난이도

| 난이도 | 분 → 시간 | 시간 → 분 |
| --- | --- | --- |
| 🌱 쉬움 | 60, 90, 120, 150, 180, 200분 | 1~3시간 + 0/30분 |
| 🌿 보통 | 70~240분, 10분 단위 | 1~3시간 + 0/10/20/30/40/50분 |
| 🌳 도전 | 70~360분, 10분 단위 | 1~5시간 + 0/10/20/30/40/50분 |

현재 난이도는 주로 **문제 숫자의 범위와 복잡도**에 차이가 있습니다. 이후에는 힌트와 시각적 도움의 정도도 난이도별로 조정할 수 있습니다.

## 🗂 프로젝트 구조

```text
time-adventure/
├── index.html   # 화면 구조 + GA4
├── style.css    # UI 및 반응형 스타일
├── app.js       # 문제 생성, 게임 상태, 정답 판정
├── .nojekyll    # GitHub Pages 정적 파일 처리
└── README.md    # 프로젝트 문서
```

빌드 과정이나 외부 라이브러리가 없는 순수 HTML/CSS/JavaScript 프로젝트입니다.

## 🚀 실행 방법

로컬에서는 저장소를 clone한 뒤 `index.html`을 브라우저에서 열거나 간단한 정적 서버를 사용하면 됩니다.

```bash
git clone https://github.com/doworld-dev/time-adventure.git
cd time-adventure
python3 -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000`으로 접속합니다.

## 📦 배포

GitHub Pages에서 `main` 브랜치의 `/ (root)`를 배포 대상으로 사용합니다.

`main`에 변경사항을 반영하면 동일한 GitHub Pages 주소에 업데이트됩니다.
